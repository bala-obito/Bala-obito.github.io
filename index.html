About

Dark Verse is an independent studio-of-one, building small browser-based tools and games with the same care usually reserved for larger products. Every piece is designed, built, and shipped end-to-end — no installs, no accounts, no clutter. Just open a link and it works.

The collection is always growing. New tools solve a single problem well; new games are meant to be picked up and enjoyed in one sitting. Everything here runs entirely in the browser, built with plain JavaScript, Canvas and WebGL, and hosted for free on GitHub Pages.
